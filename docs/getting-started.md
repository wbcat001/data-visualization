# データ可視化テンプレート集 - 使い方ガイド

## はじめに

このプロジェクトは、D3.jsを使用したReact+TypeScriptベースのデータ可視化テンプレート集です。様々なチャートやグラフのテンプレートを提供し、データ分析や情報の視覚化を簡単に実装できるようにすることを目的としています。

## 開発環境の構築

### 必要条件
- Node.js 14.0以上
- npm 6.0以上またはYarn

### インストール

1. リポジトリをクローンする
```bash
git clone <repository-url>
cd data-visualization-templates
```

2. 依存パッケージをインストールする
```bash
npm install
# または
yarn install
```

3. 開発サーバーを起動する
```bash
npm run dev
# または
yarn dev
```

これで開発サーバーが起動し、ブラウザで`http://localhost:5173`にアクセスするとテンプレートギャラリーが表示されます。

## プロジェクト構成

```
data-viz-templates/
├── src/
│   ├── components/      # 再利用可能なチャートコンポーネント
│   │   ├── charts/      # 基本チャートタイプ（棒、線、円など）
│   │   └── common/      # 共通要素（軸、凡例、ツールチップ）
│   ├── templates/       # 完成した可視化テンプレート
│   │   ├── dashboard/   # ダッシュボード向けテンプレート
│   │   ├── reports/     # レポート向けテンプレート
│   │   └── exploratory/ # データ探索向けテンプレート
│   ├── utils/           # ユーティリティ関数
│   └── data/            # サンプルデータセット
├── public/              # 静的アセットとHTMLエントリーポイント
└── docs/                # ドキュメント
    ├── templates/       # テンプレートのドキュメント
    └── components/      # コンポーネントAPIドキュメント
```

## テンプレートの使用方法

### 基本的な使い方

1. 必要なコンポーネントをインポートします。
```tsx
import { BarChart } from './components/charts/BarChart';
```

2. データを準備します。
```tsx
const data = [
  { label: 'カテゴリA', value: 20 },
  { label: 'カテゴリB', value: 35 },
  { label: 'カテゴリC', value: 15 },
  { label: 'カテゴリD', value: 40 }
];
```

3. コンポーネントを使用します。
```tsx
<BarChart data={data} width={600} height={400} />
```

### カスタマイズ

各テンプレートはプロパティを通じてカスタマイズ可能です。例えば：

```tsx
<BarChart 
  data={data} 
  width={800} 
  height={500} 
  marginTop={30}
  marginRight={30}
  marginBottom={70}
  marginLeft={70}
/>
```

詳細なカスタマイズオプションについては、各コンポーネントのAPIドキュメントを参照してください。

## テンプレートの拡張

新しいテンプレートを追加するには：

1. `src/components/charts`ディレクトリに新しいチャートコンポーネントを作成します。
2. 必要に応じて`src/templates`内の適切なディレクトリにテンプレートを作成します。
3. `docs`ディレクトリにドキュメントを追加します。

## トラブルシューティング

よくある問題とその解決方法：

- **チャートが表示されない**: データが正しい形式であることを確認してください。
- **TypeScriptエラー**: 適切な型定義が行われているか確認してください。
- **レスポンシブ対応**: ウィンドウのリサイズイベントをリッスンし、チャートを再描画する処理を実装してください。
