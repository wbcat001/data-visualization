# ズーム可能な円パッキングチャート (Zoomable Circle Packing)

このコンポーネントは、階層データを対話的に探索できるズーム可能な円パッキング可視化を実装しています。D3.jsとReactを組み合わせて、階層構造をネストされた円として表示し、クリックによるズームイン・ズームアウト機能を提供します。

## 特徴

- 階層データの直感的な可視化
- インタラクティブなズーム機能
- スムーズなアニメーション遷移
- TypeScriptによる型安全な実装
- 完全にカスタマイズ可能なサイズとデータ構造

## 使用方法

```tsx
import ZoomableCirclePacking from '../components/sample-code/zoomable-circle-packing';

// サンプルデータ構造
const data = {
  name: "root",
  children: [
    {
      name: "グループA",
      children: [
        { name: "サブグループA1", value: 100 },
        { name: "サブグループA2", value: 300 }
      ]
    },
    {
      name: "グループB",
      children: [
        { name: "サブグループB1", value: 200 },
        { name: "サブグループB2", value: 150 },
        { name: "サブグループB3", value: 220 }
      ]
    },
    { name: "グループC", value: 500 }
  ]
};

function MyComponent() {
  return (
    <div>
      <h2>階層データ可視化</h2>
      <ZoomableCirclePacking data={data} width={800} height={800} />
    </div>
  );
}
```

## Props

| プロパティ | 型 | デフォルト値 | 説明 |
|----------|------|--------------|------|
| `data` | `DataItem` | 必須 | 階層的なデータ構造。各項目は `name`、オプションの `children` 配列、またはリーフノードの場合は `value` を持つ必要があります。 |
| `width` | `number` | 928 | SVG要素の幅（ピクセル単位） |
| `height` | `number` | 928 | SVG要素の高さ（ピクセル単位） |

## データ構造

```typescript
interface DataItem {
  name: string;
  children?: DataItem[];
  value?: number;
}
```

## 動作原理

1. **レンダリング**: コンポーネントは、提供されたデータを基に円パッキングレイアウトを計算します。
2. **対話**: ユーザーが円をクリックすると、その円にズームインします。背景をクリックすると、ルートビューに戻ります。
3. **ビジュアルフィードバック**: マウスオーバー時に円の周りにストロークが表示されます。
4. **アニメーション**: ズームイン・ズームアウト時にスムーズなアニメーション遷移が適用されます。

## 実装の詳細

このコンポーネントは、Reactの `useRef` と `useEffect` フックを使用してD3.jsの可視化をReactコンポーネントにシームレスに統合しています。D3.jsのデータバインディングと選択機能を利用し、SVG要素を直接操作してインタラクティブな可視化を実現しています。

カラースケールは階層の深さに基づいて設定され、深さが増すにつれて色が変化します。各円のサイズはデータ項目の `value` プロパティに基づいています。

`Alt`キーを押しながらクリックすると、ズームアニメーションがよりゆっくりと実行され、階層構造の理解を助けます。

## カスタマイズのヒント

- カラースケールを変更して、異なる色スキームを適用できます。
- 円のパディングを調整して、密度を変更できます。
- テキストのスタイルを変更して、ラベルの見た目をカスタマイズできます。
- トランジションの時間を変更して、アニメーションの速度を調整できます。
